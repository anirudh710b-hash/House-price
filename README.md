# 🏠 House Price Prediction System

A Machine Learning project that predicts house prices based on various property features such as area, location, number of bedrooms, bathrooms, and more. This project demonstrates the use of Machine Learning for real estate price estimation.

---

## 📌 Project Overview

The House Price Prediction System helps estimate the price of a house using historical housing data and Machine Learning algorithms.

The project includes:

* Data preprocessing and cleaning
* Exploratory Data Analysis (EDA)
* Model training and evaluation
* Prediction system using trained ML model
* Flask web application deployment

This project is useful for learning practical applications of Machine Learning in the real estate industry.

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/anirudh710b-hash/House-price.git
cd House-price
```

### 2️⃣ Create Virtual Environment (Optional)

```bash
python -m venv venv
```

### 3️⃣ Activate Virtual Environment

#### Windows

```bash
venv\Scripts\activate
```

#### Mac/Linux

```bash
source venv/bin/activate
```

### 4️⃣ Install Required Libraries

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Project

Run the Flask application:

```bash
python app.py
```

Open your browser and visit:

```bash
http://127.0.0.1:5000/
```
